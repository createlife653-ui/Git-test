# coffee-asset のファイル構造メモ

このメモは、`coffee-asset` の中に何が入っているかを、自分で説明できるようにするためのアウトプット用メモです。

## まず全体

`coffee-asset` は、コーヒーの勉強ノートを入れる場所です。

ブログ記事をたくさん作るための場所ではなく、コーヒーを飲んで感じたこと、気づいたこと、調べたこと、次に試したいことを残す場所です。

英語の意味:

- `coffee` = コーヒー
- `asset` = 素材、資料、財産
- `coffee-asset` = コーヒーの学習資料置き場

## ファイルの種類

中には、主に2種類のファイルがあります。

- `.md` = Markdown、マークダウン。文字で書くメモファイル。
- `.pdf` = PDF。論文や資料を見るためのファイル。

今の `coffee-asset` には、ほとんどが `.md` のメモファイルで、1つだけ `.pdf` の資料があります。

## 一番上にあるファイル
（フォルダが一番上で一番下にファイルあるんだけど。読みにくい）
### README.md

`README` は「最初に読む説明書」という意味です。

このファイルには、`coffee-asset` の目的や使い方が書いてあります。

### AGENTS.md

`AGENTS` は「AIに向けた説明」という意味で使われています。

AIがこのフォルダを扱うときに、どう考えればいいかが書いてあります。

## フォルダ構造

```text
coffee-asset/
├─ 00_principles/
├─ 01_frameworks/
├─ 02_case_studies/
├─ 03_patterns/
├─ 04_meta/
└─ ~/
```

## 00_principles

`principles` は「原理」や「基本の考え方」という意味です。

ここには、コーヒーの味がなぜそうなるのかを学ぶためのメモが入っています。

入っている内容の例:

- 抽出の原則
- 酸味のしくみ
- 苦味のしくみ
- 甘味の感じ方
- 温度と味の変化
- 精製方法の原則
- 産地ごとの特徴
- コーヒー研究のPDF資料

英語の意味:

- `extraction` = 抽出
- `acidity` = 酸味
- `bitterness` = 苦味
- `sweetness` = 甘味
- `temperature` = 温度
- `processing` = 精製
- `origins` = 産地

## 01_frameworks

`frameworks` は「考えるための型」や「やり方」という意味です。

ここには、コーヒーをどう記録するか、どう味を見るか、どう改善するかのメモが入っています。

入っている内容の例:

- 基本の抽出レシピ
- テイスティングのやり方
- 評価の点数ルール
- 改善の回し方
- 舌の感覚チェック
- どの型をいつ使うか

英語の意味:

- `framework` = 型、考え方の枠
- `tasting` = 味を見ること
- `evaluation` = 評価
- `scale` = 点数のものさし
- `improvement` = 改善
- `loop` = くり返し
- `tongue` = 舌

## 02_case_studies

`case studies` は「実例」や「実際に試した記録」という意味です。

ここには、自分が実際に飲んだコーヒーの記録が入っています。

入っている内容の例:

- 飲んだ豆の名前
- 飲んだ日
- 淹れ方
- 味の感想
- 気づき
- 次に試したいこと

このフォルダが、一番「自分の体験」に近い場所です。

英語の意味:

- `case` = 事例
- `study` = 学び、研究
- `recipe` = レシピ、淹れ方
- `sensory` = 感覚の
- `log` = 記録
- `discovery` = 気づき、発見
- `next` = 次

## 03_patterns

`patterns` は「パターン」や「共通点」という意味です。

ここには、いくつかの記録を見てわかった傾向をまとめます。

入っている内容の例:

- 甘味のパターン
- 焙煎と苦味の関係
- 精製と酸味の関係
- 気づきのまとめ

英語の意味:

- `pattern` = パターン、くり返し見える形
- `roast` = 焙煎
- `summary` = まとめ
- `insight` = 深い気づき
（たくさんcasestudyに記事を書いたけどここまで落とし込みができていない。中をのぞくと全部英語で書いてあるんだよな。AIがファイル作ってくれたんだけどいらないからファイル消しちゃって。そしてどんなことを書けばいいかフォルダに対してのREADMEみたいな解説めもつくってほしい。例も載せて）
## 04_meta

`meta` は「全体を管理するためのメモ」という意味で使われています。

ここには、コーヒーの味そのものではなく、学習の進め方やブログとのつなげ方が入っています。

入っている内容の例:

- 学習戦略
- ブログ構成
- いったん止めている本やセミナーの案
- このファイル構造メモ

英語の意味:

- `strategy` = 戦略、進め方
- `website` = ウェブサイト
- `structure` = 構造
- `paused` = 一時停止した
- `output` = 発信、外に出すもの
- `plans` = 計画

## ~ フォルダ

`~` は少し特別な名前のフォルダです。

中には、Claudeという別のAIツールが作った計画メモのようなものがあります。

コーヒー学習の本体ではなさそうなので、まずはあまり気にしなくてよいです。

## このフォルダの使い方

自分が使うときは、次の流れがわかりやすいです。

1. コーヒーを飲む。
2. `02_case_studies` に記録する。
3. 味の理由が気になったら `00_principles` を見る。
4. 記録を続けて、共通点が見えたら `03_patterns` にまとめる。
5. 学習の進め方を整理したいときは `04_meta` を見る。
6. 人に説明できそうになったら、ブログ用の文章にする。

## 自分の言葉でまとめる

`coffee-asset` は、コーヒーの勉強机のような場所です。

飲んだ記録は `02_case_studies` に入れます。

味のしくみや基本知識は `00_principles` に入れます。

味の見方や記録のやり方は `01_frameworks` に入れます。

何回も飲んで見えてきた共通点は `03_patterns` に入れます。

学習全体の進め方は `04_meta` に入れます。

つまり、`coffee-asset` は「飲む、感じる、考える、まとめる」を残すための場所です。
