# Blog Structure / 学習ブログ構成

`coffee-blog` は集客サイトではなく、理解を確認するための「教えるつもりノート」として使う。

## Role

- `coffee-asset`: 観察、原理、仮説、比較を残す場所。
- `coffee-blog`: その時点の理解を、他人に説明するつもりで書く場所。

## Site Map

- **Home**: 最近書いた学習記事と、自分の関心テーマ。
- **Blog**: 教えるつもりで書いた理解確認記事。
- **Library**: タグからテーマ別に読み返す場所。
- **About**: コーヒーを学ぶ理由と、このブログの使い方。

## Article Types

- **Learning Note**: 原理や用語を、自分の言葉で説明する記事。
- **Tasting Reflection**: 実際に飲んだ豆から気づいたこと。
- **Experiment Log**: 抽出条件を1つ変えて分かったこと。
- **Pattern Summary**: 複数の記録から見えた傾向。

## Features To Prefer

- 味、産地、精製、抽出条件で後から探しやすいタグ。
- 記事末尾の「今回理解したこと」と「まだ分からないこと」。
- `coffee-asset` の関連ファイルへのメモリンク。
