# Coffee Atlas

`index.html` をブラウザで開くと使えます。地図、標高画像、CSS、JavaScript を含む単一ファイルです。地図の表示と操作はオフライン対応で、関連資料を開く際だけ通信が必要です。

- 北緯40度〜南緯40度の世界図、回帰線と赤道
- 10地点の山・高地と、位置を確かめる問い
- 地域の絞り込み、ベルト・標高色・地名の表示切替
- スマホでは地図内を横スクロール。地域ボタンで該当地域へ移動
- 地点一覧やキーボードからも解説を選択可能

## 編集・再生成

編集元は `tools/page.html`。地図は Natural Earth 1:50m、標高は GMT Earth Relief 6分角 / SRTM15+ v2.7。データの取得先と色分けは `tools/build.py` にあります。高原・山地の点は代表位置で、農園や産地の境界ではありません。

```powershell
python -m pip install pillow numpy netCDF4
python coffee-belt/tools/build.py
```

リポジトリのルートから実行。初回は地理データをダウンロードします。生成済みのページを閲覧するだけなら Python は不要です。

## レビューで反映した改善

- 別エージェントのコードレビューと、ブラウザでのPC・スマホ表示確認を実施。
- ケニア山とキリマンジャロ山は点の選択範囲を分離し、地名部分からも選択可能に。
- スマホでは文字を縮小しすぎず、横スクロールと地域別移動を採用。初期解説を表示位置にあるハワイと一致。
- 気候色を含む地形図から、数値標高に基づく淡色表示へ変更。広域用の平滑化データであることを明記。
- 山頂の標高と栽培地の標高、地域名の南部アフリカと国名の違いを明記。

出典のリンクはページ下部と各地点の関連資料に掲載しています。
