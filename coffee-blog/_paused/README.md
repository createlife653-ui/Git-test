# Paused Materials

ここには、現在の学習目的から外れるが、履歴として残したい資料を置く。

`coffee-blog` の今の目的は、コーヒーを教えるつもりで説明し、自分の理解を確かめること。
SNS拡散、キャンペーン、収益化、投稿数の最大化は一旦停止する。

## Contents

- `affiliate/`: Amazon アフィリエイト表示に使っていた過去のコード。
- `video-campaigns/`: SNS投稿やショート動画展開を目的にした過去のキャンペーン資料。

## Rule

- 新しく記事を書くとき、このフォルダを通常ワークフローの前提にしない。
- 再利用する場合も、学習目的に合う部分だけ取り出す。
